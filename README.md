# Probability &amp; Statistics — Interactive Companion

An interactive website and coursebook for a one-semester probability &amp;
statistics course. Everything runs as **static files**, so it hosts for free on
GitHub Pages with no server or build step.

## What's inside

```
.
├── docs/                         ← the website (GitHub Pages root)
│   ├── index.html                   landing page
│   ├── distributions.html           normal / binomial / Poisson / geometric / exponential sliders
│   ├── clt.html                     Central Limit Theorem sampler
│   ├── lln.html                     Law of Large Numbers running averages
│   ├── eda.html                     histogram bins, KDE bandwidth, percentiles &amp; IQR
│   ├── regression.html              drag-the-line least squares with live SSE
│   ├── joint.html                   bivariate-normal correlation explorer
│   ├── animations.html              gallery of the Manim videos
│   ├── assets/                      style.css, stats.js (math toolkit), site.js (nav)
│   ├── animations/videos/           rendered .mp4 animations + poster frames
│   └── pdf/                         the 69-page coursebook PDF
├── manim/scenes.py               ← Manim source for the five animations
├── build/                        ← LaTeX source for the coursebook
└── Probability_and_Statistics_Coursebook.pdf
```

The interactive graphs use [Plotly.js](https://plotly.com/javascript/) loaded from
a CDN plus a small in-browser statistics library (`docs/assets/stats.js`). Dragging
a slider recomputes and redraws instantly — there is no back-end.

## Deploy to GitHub Pages (the simple way)

1. Create a new repository on GitHub and push this folder to it:
   ```bash
   cd "Math 32"
   git init
   git add .
   git commit -m "Interactive probability & statistics site"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<your-repo>.git
   git push -u origin main
   ```
2. On GitHub, go to **Settings → Pages**.
3. Under **Build and deployment → Source**, choose **Deploy from a branch**.
4. Set the branch to **`main`** and the folder to **`/docs`**, then **Save**.
5. Wait ~1 minute. Your site goes live at
   `https://<your-username>.github.io/<your-repo>/`.

That's it — the `/docs` folder is already self-contained (it even includes a
`.nojekyll` file so GitHub serves every asset as-is).

### Alternative: GitHub Actions

If you'd rather deploy with an Actions workflow, add `.github/workflows/pages.yml`:

```yaml
name: Deploy site
on:
  push: { branches: [main] }
permissions: { pages: write, id-token: write, contents: read }
jobs:
  deploy:
    runs-on: ubuntu-latest
    environment: { name: github-pages, url: "${{ steps.deploy.outputs.page_url }}" }
    steps:
      - uses: actions/checkout@v4
      - uses: actions/configure-pages@v5
      - uses: actions/upload-pages-artifact@v3
        with: { path: docs }
      - id: deploy
        uses: actions/deploy-pages@v4
```
Then set **Settings → Pages → Source** to **GitHub Actions**.

## Run it locally

Any static file server works:

```bash
cd docs
python3 -m http.server 8000
# open http://localhost:8000
```

## Re-rendering the animations

The animations are rendered with [Manim Community](https://www.manim.community/).

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install manim                                   # needs ffmpeg + cairo/pango
cd manim
manim -qm scenes.py CLTScene                        # or LLNScene, PercentilesScene, JointScene, LeastSquaresScene
# copy the result from manim/media/videos/scenes/720p30/*.mp4 into docs/animations/videos/
```

Each scene is a small, self-contained `Scene` class in `manim/scenes.py`.

## Rebuilding the PDF

```bash
cd build
pdflatex main.tex && pdflatex main.tex              # twice, for the table of contents
```

The figures are generated by `build/make_figures.py` (matplotlib).
