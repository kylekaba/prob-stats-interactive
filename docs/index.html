Probability & Statistics, brought to life

Drag a slider and watch a distribution reshape itself. Sample thousands of times and see the Central Limit Theorem emerge. Explore the ideas from the coursebook through live graphs and Manim animations.

Start exploring → 📘 Download the book (PDF)

Eight interactive modules mirror the chapters of the book. Everything below is computed live in your browser — there is no server, so you can fork it, host it on GitHub Pages, and tinker freely.

How it works. The graphs use Plotly.js and a small statistics library, both running client-side — so dragging a slider recomputes and redraws instantly with no round-trip to a server. The animations were rendered with Manim and embedded as video. That keeps the whole site static and perfect for GitHub Pages.
